# Cascade

Folder structure templates for different business types. Pick your industry, choose how you want to organize things (Johnny Decimal, GTD, ISO 15489, etc.), and copy the commands to build it locally.

Each business type has a few different organizational philosophies to choose from, so you can find what works for your workflow.

## Heads up

**All the structures here are AI-generated right now, so don't actually use them.** This is just a test layout to see if the concept works.
